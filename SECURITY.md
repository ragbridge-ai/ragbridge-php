# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |
| < 1.0   | No        |

Security fixes are released in the latest 1.x version. Older 1.x releases do not receive
separate patches, so upgrade to the latest release to get a fix.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull
requests.

Report them privately through GitHub:

1. Open the [Security tab](https://github.com/ragbridge-ai/ragbridge-php/security) of the
   repository.
2. Choose **Report a vulnerability**, or go directly to
   <https://github.com/ragbridge-ai/ragbridge-php/security/advisories/new>.
3. Describe the issue, the affected versions and, if possible, steps to reproduce it.

You can expect an acknowledgement of your report, and a follow-up once the issue has been
assessed. A fix is prepared privately and released together with a published advisory that
credits the reporter, unless you prefer to stay anonymous.

## Scope

This policy covers the code in this repository. Vulnerabilities in the ragbridge service
itself should be reported to that project.
